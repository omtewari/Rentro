# Rentro API

Base URL (local): `http://localhost:4000`

## Health
- `GET /health` — returns service health and timestamp.

## Planned modules
- `/auth` — signup, login, OTP verification, refresh, logout, password reset.
- `/users` — user profile.
- `/properties` — property and unit management.
- `/agreements` — agreement lifecycle and document access.
- `/rent` — rent schedules, dues and rent ledger.
- `/payments` — payment initiation, status and provider webhooks.
- `/rewards` — reward ledger and eligible redemptions.
- `/notifications` — notification preferences and history.

Endpoints are intentionally marked as planned until their authorization, validation and business rules are implemented.
